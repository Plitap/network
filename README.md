# PLITAP · Сетевой уровень

Сетевые механизмы поиска участников, установления соединений и доставки данных PLITAP.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Обнаружение участников, прямые соединения и независимая ретрансляция.
- Передача частями, очереди, повторные запросы и продолжение после обрыва.
- Проработка интернет-связи, Wi-Fi, Bluetooth и доступных спутниковых каналов.

## Границы направления

Доставка данных не подтверждает переход владения. Общие правила сообщений относятся к [spec](https://github.com/Plitap/spec), проверка плитки — к [core](https://github.com/Plitap/core). Перечень каналов обозначает направления работы; готовая поддержка устройств и операторов не заявляется.

## Структура

| Раздел | Назначение |
|---|---|
| [`src/`](src/) | Исходный код обнаружения, соединений, доставки и управления сетевыми ресурсами. |
| [`tests/`](tests/) | Проверки соединений, обрывов, повторов, смены канала и ограничений ресурсов. |
| [`docs/`](docs/) | Проектирование сетевого уровня и инструкции его разработки. |
| [`docs/discovery/`](docs/discovery/) | Поиск первых контактов и участников без единственного обязательного адреса PLITAP. |
| [`docs/transports/`](docs/transports/) | Сравнение способов доставки и требований к адаптерам каналов. |
| [`docs/transports/internet/`](docs/transports/internet/) | Интернет-соединения, NAT, прямые пути и ретрансляторы. |
| [`docs/transports/local/`](docs/transports/local/) | Локальная сеть, Wi-Fi и обнаружение ближайших устройств. |
| [`docs/transports/bluetooth/`](docs/transports/bluetooth/) | Возможности Bluetooth, межплатформенная совместимость и ограничения устройств. |
| [`docs/transports/satellite/`](docs/transports/satellite/) | Доступные спутниковые каналы, ограничения ОС и операторов, задержки и объём данных. |
| [`docs/delivery/`](docs/delivery/) | Возобновление передачи, очереди и работа при периодической доступности связи. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/network/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
